# epanel-plugin-mc-tools

适用于 ElementsPanel 的 Minecraft 工具插件，支持 Java 版和基岩版服务器状态查询、存档地图查看及玩家管理。

Java 版地图可通过 RCON 定时显示在线玩家、坐标和朝向。侧边栏的“玩家”页面支持按名称搜索和点击定位，2D、3D 地图均显示玩家头像。打开实例地图时，若 RCON 未启用，会请求确认；确认后更新 `server.properties`，在缺少密码时生成随机密码，并请求重启实例。

RCON 连接由 daemon 按实例长期复用，刷新或关闭地图不会主动断开；断线后在下次读取时重连，实例停止或插件卸载时清理连接。

出生点使用 Minecraft 指南针图标。2D 和 3D 均支持左键拖动平移、右键拖动旋转；点击地图后可按住 WASD 或方向键平滑移动，支持同时按下多个方向键斜向移动，松键即停。右上角朝向按钮实时显示角度，点击可恢复北向朝上，并保留位置、缩放和 3D 倾角。

头像根据玩家名称通过 Mojang API 查询皮肤，缓存六小时，查询失败时使用默认头像。公开地图只显示其配置世界中的玩家。
